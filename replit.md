# RT Study Program

A comprehensive Respiratory Therapy (RT) study and test application to help students prepare for NBRC TMC credentialing exams. Students can study 10 topic modules, take topic quizzes, a 60-question comprehensive exam, review session history, and track progress.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL` — Postgres connection string

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- Frontend: React + Vite + Wouter routing, shadcn/ui, Tailwind CSS (teal/clinical theme)
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

- `artifacts/rt-study/` — React+Vite frontend web app (previewPath: `/`)
- `artifacts/api-server/` — Express 5 API server (previewPath: `/api`)
- `lib/api-client-react/src/generated/api.ts` — Orval-generated hooks + Zod schemas (source of truth for API types)
- `artifacts/api-server/src/db/schema.ts` — Drizzle schema (source of truth for DB)
- `artifacts/api-server/src/openapi.yaml` — OpenAPI spec (source of truth for API contract)

## Architecture decisions

- Contract-first: OpenAPI spec → Orval codegen → typed hooks used in frontend; server validates with generated Zod schemas
- Session model: a `sessions` row tracks mode (`topic`|`practice`|`exam`), questions, answers, and score; completing a session triggers score calculation server-side
- Questions store `options` and `keyPoints` as JSON strings in TEXT columns (parsed by the API layer before returning)
- All API mutations take `{ id, data }` shape as generated by Orval — no sessionId is baked into hook initialization
- The test interface (`/test/:sessionId`) renders outside the sidebar Layout (full-screen focus mode)

## Product

- **Dashboard** — stat cards (avg score, questions attempted, topics mastered, sessions), quick actions, per-topic progress bars
- **Study Topics** — 10 RT topic cards with question counts and mastery progress; each opens a full study page with key points + detailed notes
- **Topic Quiz** — launches a session for any single topic; all topic questions included
- **Comprehensive Exam** — 60-question randomly sampled exam across all 10 topics
- **Test Interface** — single-question-at-a-time with A/B/C/D answer buttons, immediate feedback, color-coded results, explanation panel, navigation
- **History** — chronological list of all sessions with scores and continue/review actions
- **Session Review** — full post-session answer review with correct/incorrect indicators and explanations for every question
- **Progress** — per-topic breakdown with mastery bars and aggregate stats

- Do not change this application ID; Google Play updates must keep the same identity and upload signing key.

## Gotchas

- When running `pnpm --filter @workspace/rt-study run typecheck`, use `typecheck` not `build` — build needs `PORT`/`BASE_PATH` env vars provided by workflows
- The `useSubmitAnswer()` and `useCompleteSession()` hooks (Orval-generated) do NOT take sessionId as a hook argument — pass `{ id: sessionId, data }` to `.mutate()`
- `index.css` Google Font imports must be the very first line before `@import "tailwindcss"`
